# KaguyaIDE v3.0.0

## AI-Powered Coding Assistant with Autonomous Agent

### Quick Start

**Windows:**
  Double-click `KaguyaIDE.bat` or run in PowerShell:
  ```
  .\KaguyaIDE.bat
  ```

**macOS / Linux:**
  ```bash
  chmod +x KaguyaIDE.sh
  ./KaguyaIDE.sh
  ```

**Python mode (all platforms):**
  ```
  pip install -e .
  kaguya-ide
  ```

### Configuration

1. Open http://localhost:5000 in your browser
2. Configure your AI API key in Settings > API Center
3. Supported providers: DeepSeek, Qwen, Claude, OpenAI, Gemini

### Features

- Autonomous coding agent with file operations
- Web-based IDE with terminal integration
- Multi-model support (Ollama, DeepSeek, Qwen, Claude, etc.)
- Permission management system
- Skill framework and plugin system
- Account management with JWT authentication
- ACP (Agent Client Protocol) integration

### System Requirements

- Python 3.9+ (for Python mode)
- 2GB RAM minimum
- Modern web browser (Chrome, Firefox, Edge, Safari)
